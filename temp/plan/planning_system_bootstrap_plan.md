# planning_system_bootstrap_plan

Task ID: `planning_system_bootstrap`
Task Name: `计划系统初始化`
Overall Status: Done
Current Phase: `M4 - 收尾`

## 目标
为仓库建立可复用的里程碑计划机制，并加入仓库级 agent 约束，要求每个非琐碎任务都显式跟踪计划。

## 范围
纳入范围：
- 在 `temp/plan/` 下建立主计划索引
- 建立首个任务的计划与完成记录
- 更新 `AGENTS.md`，加入强制计划规则

不纳入范围：
- 回填历史任务
- 为尚未提出的未来任务提前建计划
- 修改构建或源码行为

## 已确认决策
- `temp/plan/` 是唯一正式计划根目录。
- 每个任务都使用三文件模型。
- 里程碑阶段统一为 `M1` 到 `M4`。
- agent 不得在没有计划条目的前提下执行非琐碎工作。

## 里程碑拆分
- `M1 - 设计`: 定义计划结构与仓库规则。
- `M2 - 实现`: 创建 `plan.md` 与任务文件，更新 `AGENTS.md`。
- `M3 - 验证`: 检查链接、命名与流程一致性。
- `M4 - 收尾`: 将初始化任务标记完成，并留下后续维护规则。

## 风险与注意点
- 后续贡献者可能更新任务文件但忘记同步 `plan.md`。
- 小改动如果不严格执行规则，仍可能绕过计划机制。

## 依赖
无。

## 后续动作
- 后续新任务继续沿用该结构。
- 在开始实质实现前，先把新任务登记进 `plan.md`。
